# SENTINEL Design System v2.1

Status: ACTIVE

Design System v2.1 keeps the v2 security, authority and accessibility semantics and applies the Owner-approved shield/S/signal depth identity across Android, Web, Companion and the presentation overlay.

## Identity
The primary mark is a shield-like S with bounded signal arcs and a single signal node. Depth and cyan/teal material gradients are reserved for the brand asset. Normal cards, controls and application backgrounds remain restrained and structural. Scanner sweeps, persistent glow, cyberpunk grids, RGB ambience and military imagery are prohibited.

## Dark tokens
Canvas #061018; Surface #0D1B29; Raised #13263A; Sunken #091722; Border #29485F; Strong border #3A627D; Primary #2DD4FF; Signal #00E0C2; Verified #22C55E; Warning #F59E0B; Danger #F43F5E; Text #E6F1F7; Secondary text #A6B7C5.

Light mode preserves the v2 accessible light palette.

## Typography
Onest is display/brand. Inter is UI/body. JetBrains Mono is reserved for fingerprints, IDs, timestamps and technical evidence.

## Status model
VERIFIED / ACTIVE / PENDING / WARNING / DENIED / REVOKED / FAILED / UNKNOWN / UNAVAILABLE / STOPPED. Every status has text. Unknown, unavailable, denied and revoked states never inherit verified styling.

## Android
Home prioritizes Account → Device → Required action, followed by game access, bounded activity and support. Security is a hub routing to Account security, MFA, Recovery, Sessions, Device identity and Linked providers. Destructive actions are scoped to detail surfaces.

## Web
The end-user control plane uses a stable desktop navigation rail, solid structural surfaces and four responsive ranges. Account, access and intelligence are separate groups. Admin is a separately scoped privileged utility.

## Companion
Companion is a desktop system tool with Overview, Account, Runtime, Host configuration, Games, Voice and Diagnostics. Stop/kill remains immediately reachable but visually bounded. Voice and overlay remain presentation-only.
