physical numeric calibration and presentation-only recommendations. Its actual
Infinix package/version/language/HUD must be collected from the installed game;
an upstream source SHA does not establish installed identity.

The closed `sentinel-turn-fixture` contract in
[GAME_ACTION_OFFLINE_V1.md](GAME_ACTION_OFFLINE_V1.md) exercises action plumbing
without controlling any game. None of the catalog rows gains an executor or L3
capability from that replay. Global `AUTOMATIC_EXECUTION_DISABLED` remains active.
Mindustry's documented removable-module path remains a subsequent isolated-world
candidate after prerequisites; Luanti is a distinct engine/world alternative.

Every future adapter must separately establish source identity, publisher
permission, measured freshness/latency, calibrated context, authenticated
principal/entitlement, bounded consent and semantic action, and a new observed
outcome. Screen capture does not attest the selected app, and delivering input
does not prove game success. Historical confirmed rows are not reopened by this
research; version-sensitive policy must be rechecked when implementing them.
